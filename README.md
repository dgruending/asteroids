# Asteroids

This is a simple recreation of the classic Asteroids using pygame.

## Python version

This script is developed for Python version 3.11.

## Installation

1. Clone repository: `git clone https://github.com/dgruending/asteroids.git`
1. Install requirements: `pip install -r requirements.txt`
1. Call script: `python main.py`

## Controls

Movement: <kbd>W</kbd>, <kbd>S</kbd> 

Rotation: <kbd>A</kbd>, <kbd>D</kbd>

Shoot: <kbd>Space</kbd>
